## 종합
원본 충실성·규칙 준수 모두 양호. 빌드/린트/타입 전부 통과. 직접 수정한 항목 없음(치명적·사소 결함 미발견). 남은 이슈 1건은 판단이 필요해 보고만 함.

## 통과 항목
- 7개 섹션(Header/Hero/Ranking/TicketOpen/GenreExplore/NoticePromotion/Footer) 모두 존재, 조립 순서 스펙과 일치.
- 콘텐츠 데이터 전량 일치: 랭킹 4개(Wicked 8.5%/Hamilton 7.2%/Les Misérables 6.9%/The Play 5.5%), 티켓 2개(Chicago D-3 2024.11.20 14:00 / Beethoven D-7 2024.11.24 10:00), 장르 3개, 공지 3건(11.15/11.12/11.10), 푸터 SERVICES·SUPPORT·NEWSLETTER·카피라이트·Privacy/Terms.
- 이미지 경로 `/images/*` 전량 존재·정확. 모든 `<img>`/`next/image` alt 부여.
- 규칙: Tailwind 흔적 0(주석 언급만), 순수 SCSS, `@use`만 사용(@import 0), `any` 0, props 타입 명확.
- SCSS 네스팅 3depth 이내, 꾸밈요소 전량 `::before/::after`(header glass, ranking/ticket glow, rank number, genre 안쪽보더, membership glow, noise overlay).
- 토큰 참조 준수. 하드코딩 rgba(배지 배경, membership glow, link 밑줄)는 대응 토큰이 없고 handoff가 해당 리터럴을 명시한 케이스라 허용 범위.
- 공통화 실체 확인: 모든 버튼이 공통 `Button`(primary/glass/white/link/text/icon/ghost)으로 통합, 카드 중복은 `media-frame`/`zoom-image`/`icon-circle` mixin으로 정리. 잔존 인라인 버튼/중복 없음.
- 접근성: `header/main/footer` 랜드마크, 섹션 `aria-labelledby`(NoticePromotion은 sr-only h2), 아이콘 버튼 aria-label(검색/메뉴/공지 더보기/구독/웹사이트/공유), heading h1(Hero) 1개 유지.
- 반응형: 모바일 햄버거 토글 실동작 확인(☰↔✕, 드롭다운에 MUSICAL 활성/PLAY/CONCERT/EXHIBIT), md/lg 분기·컨테이너 패딩(24/80) 정상. 390px에서 가로 오버플로 없음(bodyScrollW=390).

## 남은 이슈
### [Low] 모바일(≤~410px) 헤더 "MY TICKET" 버튼 라벨 2줄 줄바꿈
- 현상: 390px에서 `.btn--primary`(MY TICKET) 라벨이 "MY / TICKET" 2줄로 접혀 pill이 부풀어 보임. 기능/가독성은 정상, 햄버거·검색 모두 화면 내 위치(clip 없음).
- 원인: 좁은 폭에서 로고+검색+구분선+MY TICKET+햄버거 + 24px gap 합이 커져, 버튼이 폭에 맞춰 라벨을 wrap. `white-space:nowrap`만 주면 이번엔 폭 초과(오버플로)로 역효과 → gap 축소 등 모바일 헤더 구성 조정이 동반돼야 함.
- 조치: **직접 수정 안 함(보고)**. 원본에 모바일 헤더 스펙이 없고(핸드오프상 모바일 메뉴 자체가 "기획서에 없음"), 수정하려면 모바일 gap/패딩/노출요소에 대한 디자인 판단이 필요해 사용자 결정 권장.
- 권장안(택1): (a) 모바일에서 `.header__actions` gap 24→12px + MY TICKET `white-space:nowrap`, (b) 모바일에서 MY TICKET 좌우 패딩 축소, (c) 모바일에서 MY TICKET을 드롭다운 메뉴로 이동.

## 참고(결함 아님)
- Hero 제목 `clamp(40px,12vw,72px)`: 원본 고정 72px 대비 축소 적용이나, handoff가 모바일 가독성용으로 명시 제안·"확인 필요"로 열어둔 항목 → 의도된 편차.
- RankCard 메타에서 긴 장소명(SEJONG CENTER 등)일 때 "장르|장소"와 퍼센트가 붙어 보임 → 원본도 동일 레이아웃(gap 없음). 원본 충실. 필요 시 meta에 소폭 gap 추가로 개선 가능(원본과의 미세 편차 감수).
- Footer 컬럼 제목 h3가 footer 내 상위 h2 없이 등장 → 경미한 heading 위계 nit. 심층 a11y는 frontend-reviewer 영역.
